# 🚀 AI Career Copilot

An AI-powered web application that analyzes resumes and provides career insights, skill gap analysis, and personalized recommendations.

---

## 🔥 Features

- 👤 User Authentication (Signup/Login)
- 📄 Resume Upload (PDF/DOCX)
- 🤖 AI-Powered Resume Analysis
- 💪 Strength Detection
- ⚠️ Missing Skills Identification
- 🎯 Career Goal Based Suggestions
- 📚 Resume Analysis History
- 💾 Database Integration
- 🌐 Responsive Web Interface

---

## 🛠 Tech Stack

- Python
- Flask
- HTML
- CSS
- SQLAlchemy
- SQLite
- PyPDF2
- python-docx
- Git & GitHub
